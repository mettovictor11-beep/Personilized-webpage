# Personalized Webpage

A simple personalized webpage that stores a visitor's name and age in browser local storage, displays a greeting, calculates age in months, and shows motivational quotes.

## Features

- Personalized greeting using the saved name
- Age input with conversion to months
- Local storage persistence so the information stays after refresh
- Five motivational quotes displayed on the page
- Responsive and visually appealing styling

## Files

- `index.html` — page structure
- `style.css` — styling and layout
- `script.js` — form handling, local storage logic, age calculation, and quote rendering

## How to run

1. Open the project folder in a browser.
2. Open `index.html` directly in your browser, or use a simple local web server.
3. Enter your name and age.
4. Submit the form to see your personalized greeting and age in months.

## Example

When a user enters:

- Name: Alice
- Age: 5

The webpage will display a greeting such as:

Hello Alice! Welcome to your personalized webpage.

And the age section will show:

You are 60 months old.

## Notes

This project uses browser local storage, so the saved name and age remain available on the same browser until cleared.
